# NYC Yellow Taxi Analytics Dashboard

## Overview
An interactive Power BI dashboard analysing NYC yellow taxi trip revenue, trip patterns, payment methods, and pickup-zone performance.

## Dashboard Preview

![NYC Yellow Taxi Analytics Dashboard](./Screenshot%202026-10-20%20111003.png)

## Key Performance Indicators

- **Total Revenue:** 100.16M
- **Total Trips:** 3.33M
- **Average Trip Distance:** 3.6 miles
- **Average Trip Duration:** 17.3 minutes
- **Average Speed:** 11.2 MPH
- **Average Fare:** $20.98
- **Card Tip:** 22.4%

## Dashboard Features

- Revenue trends by hour
- Revenue by trip type
- Average speed by hour
- Revenue by payment method
- Top five pickup zones by revenue
- Interactive trip and weekday filters

## Tools Used

- Microsoft Power BI
- NYC yellow taxi trip data

## Business Questions

1. How does revenue change throughout the day?
2. Which trip type generates the most revenue?
3. How does average speed vary by hour?
4. How is revenue distributed across payment methods?
5. Which pickup zones generate the most revenue?
